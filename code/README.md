# Project Code

Python scripts and Jupyter notebooks for all projects in *Think Python, Direct AI*.

## Quick Start

**Option 1: Run locally**
```bash
python temperature-converter.py
```

**Option 2: Run in Google Colab (no install needed)**
Open any `.ipynb` file and click the "Open in Colab" badge at the top. Colab includes Google Gemini for AI-assisted coding.
